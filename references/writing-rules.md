# 去学术化规则、禁词与诚信红线

## 一、去学术化清单（命中即改写）

| 学术痕迹 | 问题 | 处理 |
|---|---|---|
| 某某（2023）指出／已有研究表明 | 文献痕迹 | 删除，直接陈述事实或判断 |
| 理论框架／分析框架／概念界定 | 理论铺陈 | 删除，直接进入问题 |
| 基于某某理论视角 | 学理包装 | 删除，写实际分析 |
| 本文／本研究表明 | 论文腔 | 改为直接陈述或"调研发现" |
| 显著性检验／回归结果／相关性 | 方法术语 | 转为通俗表述："调研显示 X 与 Y 明显相关" |
| 范式／话语／建构／解构／场域 | 学科黑话 | 换成日常表达 |
| 综上所述／由此可见 | 论文收束语 | 删除，直接给建议 |
| 参考文献列表 | 文体不符 | 一律删除，来源标注写入正文 |

## 二、术语转化对照表

学术表达转决策表达：

| 学术表达 | 决策表达 |
|---|---|
| 存在结构性失衡 | 资源集中在少数地区／环节，多数地区跟不上 |
| 机制不健全 | 缺少明确的责任分工和流程规定 |
| 主体性缺失 | 基层没有发言权和决定权 |
| 路径依赖 | 长期沿用老办法，难以改变 |
| 制度供给不足 | 现有规定覆盖不到新情况 |
| 协同效应尚未形成 | 各部门各管一摊，没有形成合力 |

## 三、禁词与慎用表述

### 禁词（出现即删改）

1. 理论性禁词：理论框架、概念界定、学理分析、范式、话语体系、建构、解构、场域、惯习、张力
2. 论文腔禁词：综上所述、由此可见、本文认为、研究表明（引用他人时除外）
3. 情绪化表述：令人震惊、触目惊心、极其恶劣、前所未有
4. 绝对化断言：必将、必然导致、完全不可能、没有任何作用
5. 空泛对策词（单独使用时）：加强重视、提高认识、强化领导、狠抓落实——必须接具体动作，否则删除

### 慎用表述（需有依据或改为温和表述）

1. 程度词：严重、极其、大幅、急剧——需数据支撑
2. 判断词：失败、错误、不当——改客观描述
3. 对比词：落后于、优于——需注明比较基准与来源

## 四、数据诚信与来源标注

1. 所有数据必须真实：来自用户提供的调研、公开统计或权威发布
2. 无法核实的数据一律不写，标注"待补数据"并写明需要哪类数据
3. 数据来源在正文随文标注，格式简洁：据某部门某年统计、据某年某调查报告
4. 不使用未公开的内部数据，除非用户明确说明已获授权
5. 数据时效性说明：超过三年的数据标注年份，避免误读为现状
6. 预测性数据标明为预测而非事实

## 五、脱敏与安全

报送对象是党政部门，内容安全标准高于公开出版物。

| 检查项 | 处理 |
|---|---|
| 具体人名（非公众人物） | 改为职务或"某负责人" |
| 未公开的单位内部数据 | 提示用户确认可否使用，必要时改为区间或趋势表述 |
| 涉密信息 | 立即停止使用并提示用户，不写入正文 |
| 具体企业、机构负面信息 | 改为行业或类型表述，避免指向特定主体 |
| 个人隐私信息 | 删除 |
| 未经证实的社会传闻 | 不使用 |

处理规则：命中即替换或删除，同时在交付说明中列出处理位置，请用户确认。

## 六、语言纪律

1. 单句尽量短，一句一个意思
2. 不用生僻字，不用成语堆砌，不用比喻修辞装点门面
3. 段落不长，重要内容独立成段
4. 数字与事实为主，形容词为辅
5. 不谄媚（不用"恳请领导高度重视"式表达），不训导（不用"必须清醒认识到"式表达）
6. 建议用"建议"开头或直接陈述动作，语气客观

## 七、修改任务的诊断流程

接手修改任务时按顺序执行：

1. 逐条扫描：用去学术化清单、禁词表、数据来源、脱敏项逐条对照原文
2. 出诊断表：命中项、所在位置、违反的规则、修改思路
3. 改写：逐项落实，保留原文的真实信息与用户观点
4. 附修改说明：改了什么、为什么改，供用户判断是否接受
