# 咨政建言报告撰写 Skill（policy-advisory-report）

一个面向高校教师、科研人员的咨政建言写作 Skill：把研究成果转化为决策部门能看懂、能采用的建议，专治学术腔。

## 它做什么

- 按 **"提出问题—分析评价—对策建议"三段式**成稿，对策建议**不少于全文三分之一**
- **字数分档**：快报型3000 字 / 标准型 5000 字 / 深度型 6500 字，上限 8000 字
- **去学术化改写**：清除理论铺陈、文献痕迹、学科黑话，附术语决策化转化对照表
- **每条建议四要素**：做什么、谁来做、怎么做、预期效果——建议能直接拿起来用
- **数据来源标注**：所有数据真实可溯，查不到的标注"待补数据"而非编造
- **脱敏检查**：人名、未公开数据、具体机构负面信息、涉密内容逐项排查
- **不写参考文献**，摘要默认不产出（渠道明确要求时才写）

## 安装

将 `policy-advisory-report` 文件夹放入 `~/.workbuddy/skills/` 目录（或下载 ZIP 解压到该位置）。

## 怎么触发

- "把这个课题成果写成咨政报告"
- "写一份关于某问题的决策建议"
- "给领导提个建议"
- "帮我把这篇论文改成要报"

注意：学术论文、政府公文、商业计划书不会误触发，边界清晰。

## 文件结构

```text
policy-advisory-report/
├── SKILL.md                          # 使用时机、工作流程、四项检查、三条纪律、红线
└── references/
    ├── writing-standards.md          # 三段式写法、字数档位、对策打磨法、语言规范
    ├── writing-rules.md              # 去学术化清单、术语转化表、禁词、诚信与脱敏
    └── output-templates.md           # 三类任务模板与论文改要报完整示例
```

## 核心逻辑

咨政建言不等于学术论文。领导要看的不是理论普及，而是针对问题的解决方案——很多问题他们知道，缺的是怎么解决。本 Skill 的全部规则都服务于这一点：把学术发现翻译成能落地的决策语言。

## 免责声明

本 Skill 辅助撰写报告文字，观点与判断归属使用者本人；不代替向任何部门投稿报送；数据与政策依据以使用者提供的真实素材和现行文件为准。
